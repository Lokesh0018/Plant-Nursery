# PROJECT: PREMIUM PLANT NURSERY WEBSITE WITH SCROLL-DRIVEN PNG PARALLAX

Act as a senior creative frontend developer, UI/UX designer, and GSAP animation specialist. Build a complete, production-quality, premium plant nursery e-commerce website inspired by the provided Pinterest reference video and screenshot.

The website must have the same minimalist editorial design language, oversized isolated plant PNG, elegant typography, floating product purchase panel, and scroll-driven transitions.

IMPORTANT: The primary visual effect must use transparent PNG images and scroll-driven parallax. Do not replace the plant with a rotating 3D model. The plant should look like a real product photograph that moves naturally as the user scrolls.

Do not just create a static mockup. Implement the complete responsive website with working navigation, animations, product interactions, and smooth transitions.

---

# 1. TECHNOLOGY STACK

Use the following technologies:

* React with Vite
* JavaScript or TypeScript
* GSAP for animation
* GSAP ScrollTrigger for scroll-driven animation
* Lenis for smooth scrolling
* CSS Modules or well-organized global CSS
* Lucide React for icons

Use React components to organize the application.

Do not use unnecessary animation libraries alongside GSAP. Use CSS transitions for simple hover effects.

Use requestAnimationFrame-compatible animation patterns and properly clean up GSAP timelines and ScrollTriggers when React components unmount.

# 7. PNG PLANT PARALLAX ANIMATION

This is the most important animation of the entire website.

Use a transparent PNG of a realistic potted plant. The PNG must have a clean transparent background and high resolution.

Place the PNG inside a dedicated plant container.

Implement the animation with GSAP and ScrollTrigger.

INITIAL STATE:

* Plant is positioned on the left side of the hero.
* Plant is fully visible.
* Plant has a natural scale of 1.
* Product details are visible on the right.
* The hero occupies the full viewport.

SCROLL ANIMATION:

* Pin the hero section during the main transition.
* As the user scrolls, move the plant upward.
* Use a carefully tuned vertical translation.
* Slightly scale the plant during the transition.
* Keep the plant's movement smooth and continuous.
* The plant should appear to move independently from the text and background.
* Do not rotate the plant aggressively.
* Avoid sudden jumps or abrupt changes.
* Use scrub-based animation so the movement is directly controlled by scroll position.

During the scroll:

1. The plant gradually moves upward.
2. The plant becomes partially cropped at the top of the viewport.
3. Product information gradually fades or moves away.
4. The background transitions from sage green to warm cream.
5. The next section starts appearing beneath the hero.
6. The next section's heading and product cards reveal progressively.

The entire animation must reverse naturally when scrolling upward.

Do not make the plant disappear instantly. It must move out of view naturally.

Use GSAP timelines with ScrollTrigger and scrub: 1 or a similarly smooth value.

Use appropriate start and end positions. Tune the animation for real browser scrolling, not just a demo.

IMPORTANT:

* The PNG plant must remain sharp.
* Do not distort the plant's aspect ratio.
* Do not use a CSS background image for the plant.
* Use an actual img element with object-fit: contain.
* Do not animate the plant using an infinite floating loop that conflicts with scroll control.
* Avoid layout shifts during the pinned animation.

The website must work on desktop, tablet, and mobile.

DESKTOP:

* Reproduce the reference's two-column product hero.
* Large plant on the left.
* Product information on the right.
* Floating purchase panel.

TABLET:

* Reduce plant size.
* Maintain clear spacing between image and content.
* Adapt the purchase panel width.
* Ensure the pinned transition does not cause overflow.

MOBILE:

* Use a vertically stacked product layout.
* Navigation collapses into a mobile menu.
* Plant image appears prominently above the purchase panel.
* Product details remain readable.
* Disable or simplify complex pinning if it harms usability.
* Keep scroll animations smooth and natural.
* Prevent horizontal scrolling.

# 18. PERFORMANCE AND ACCESSIBILITY

Performance:

* Optimize and compress images.
* Lazy-load images below the fold.
* Preload the hero plant PNG.
* Avoid unnecessarily large animation timelines.
* Prevent layout shifts.
* Use will-change only on elements that are actively animated.
* Clean up ScrollTriggers when components unmount.
* Avoid unnecessary React re-renders during scrolling.

Accessibility:

* Use semantic HTML.
* Add meaningful alt text to plant images.
* Ensure keyboard-accessible buttons and navigation.
* Provide visible focus states.
* Respect prefers-reduced-motion.
* Ensure adequate text contrast.
* Make all purchase controls usable without a mouse.

# 19. GSAP IMPLEMENTATION REQUIREMENTS

Use GSAP context or an equivalent cleanup pattern inside React effects.

Register ScrollTrigger properly.

Use a single coordinated timeline for the hero transition wherever practical.

The animation should:

* Be scroll-scrubbed
* Pin the hero on desktop
* Move the PNG plant vertically
* Fade the product information
* Transition the background
* Reveal the next section
* Reverse correctly when scrolling upward

Avoid creating multiple conflicting ScrollTriggers for the same element.

Use invalidateOnRefresh where necessary.

Recalculate animation measurements after images load if needed.

Do not use fixed pixel offsets that break on different viewport sizes. Prefer responsive calculations and functional GSAP values.
